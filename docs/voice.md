# The voice

The mandate for this project is two words: **cool and hilarious**. This page is
how we keep it both. Read it before writing a single line that a boot screen,
an error message or the README will show.

## The rules

1. **The machine never knows it is funny.** Deadpan, always. No exclamation marks, no emoji, no winking, no "lol". A BIOS from 1995 reports the presence of a unicorn in exactly the tone it reports the presence of a hard disk.
2. **Start from the real thing and change one word.** "38911 BASIC BYTES FREE" becomes "38911 SPARKLES FREE". The closer the rest stays to what people remember, the harder the one wrong word lands.
3. **Facts are sacred, fiction is branding.** Anything that reads like a diagnostic must be true of the user's machine. Fiction lives in vendor names, model numbers, horns, sparkle, glitter and enchantment. The test: could a tired person mistake this line for a real problem? If yes, it has to be a real problem.
4. **Specific beats wacky.** "IRQ 7 assigned to: glitter" is funny. "Unicorns are so random" is not. Period detail is the joke: IRQs, turbo buttons, shadow RAM, parity, cassette BASIC, the floppy drive nobody has.
5. **One line.** If it needs a second line it is not a quip, it is a bit, and bits belong in the README.
6. **Punch at the machine, the era, or the user's hardware envy.** Never at people.
7. **The unicorn is hardware.** It is detected, enumerated and 7-band. It is never cute, never drawn with hearts, and never speaks.
8. **Rarity is part of the joke.** Quips rotate so the same person sees a new one next week. The best ones should be rare, and a few should only ever appear on one day of the year.
9. **Cool comes from craft.** The colours are period correct, the timing is right, the columns line up, and it never slows the shell. A sloppy joke is a bad joke.

## The lexicon

Use these, and keep them consistent everywhere:

| Term | Meaning |
|---|---|
| Rainbows & Unicorns, Inc. | The fictional vendor |
| Sparkle Corp | Its 1985 predecessor, seen on older machines |
| Sparkle Modular BIOS | The firmware |
| UNI-440BX | The chipset |
| The UNICORN Personal Computer | The 1985 model |
| horn | The peripheral. One per machine. Not hot-swappable |
| 7-band | The horn's specification. Always seven |
| sparkle | The unit. Sparkle memory, sparkles free, sparkle capable |
| glitter | What goes wrong. Glitter in the drive, IRQ assigned to glitter |
| Enchantment Star | The compliance programme |
| beige | The fail-safe. Everything off, everything grey |

## Good and bad

| Good | Why |
|---|---|
| Turbo button engaged. It does nothing. It never did. | True, specific, deadpan |
| 640K ought to be enough for anybody. You have 37748736K. Show-off. | A real number makes it personal |
| Floppy drive A: not found. Nobody is surprised. | Technically a true diagnostic |
| Warning: horn is not hot-swappable. | The unicorn is hardware |

| Bad | Why |
|---|---|
| Unicorn power activated!!! | Excited, generic, knows it is a joke |
| Hard disk failure imminent | Sounds real and is not. Breaks rule 3 |
| Loading awesomeness... | Could be any project |
| *a meme reference* | Dates instantly, and 1985 had none |

## Who writes the jokes

Every line a screen shows is written by a person who has read this page, and is
reviewed like code. Wording is never generated at runtime and never left to
whoever happens to be implementing the feature.
