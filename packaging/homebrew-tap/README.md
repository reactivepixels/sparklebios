# reactivepixels/homebrew-tap

The Homebrew tap for [sparklebios](https://github.com/reactivepixels/sparklebios). `Formula/sparklebios.rb` is kept current by a scheduled workflow, not by hand; see the comment at the top of that file and of `.github/workflows/update-formula.yml`.

Install with:

```
brew install reactivepixels/tap/sparklebios
```
